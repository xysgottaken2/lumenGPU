Put your own permitted local image files (PNG, JPG, DDS DXT1/DXT3/DXT5) in textures and Roblox-format mesh files in meshes. Names must use ASCII letters, digits, underscores, dashes and periods. Built-in rbxasset:// references resolve by filename, local overrides first, then supported Roblox installation content paths. Restart LumenBridge after changing files. No Roblox asset files are bundled. Local files need no OAuth. Numeric asset IDs still use the existing authorized delivery path.

V0.10.0 built-in material preview: current official Roblox base map IDs, lazily requested through existing authorized Lumenus; classic places prefer matching local previews, otherwise official color; modern places prefer official then local _2022 then classic. Local files are not distributed. Extract mtrl_*.png from your own TerrainTools folder into materials/ beside LumenBridge.exe (or textures/). Maps are requested only when the official color succeeds; missing normal/roughness/specular estimated in shader when Generated PBR is enabled, metalness uses class prior. Existing explicit mesh textures, SurfaceAppearance and decals take precedence. World-space dominant-axis projection, four studs per tile (workspace attribute LumenMaterialStudsPerTile), also applied to existing terrain mesh rows. This is not seamless blended triplanar or Roblox's exact shader. No new rays. 72 built-in requests within the existing 128 total texture slots; failed requests count toward cap. Small source images bilinearly resized to atlas minimum 256. Workspace LumenBuiltinMaterials=false disables; LumenUse2022Materials boolean overrides place setting if needed. Requires restart and reinstall. MaterialVariant overrides and terrain details not supported by this initial implementation. Light tracker retained; runtime performance and authorized API access unverified.
