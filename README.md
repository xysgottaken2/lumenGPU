# LUMEN GPU 0.5 — Mesh geometry

[Windows builds](../../actions) | [Setup and limitations](README.txt)

Exports readable MeshPart and FileMesh assets (including rigid accessory handles) using Roblox EditableMesh. Cached triangle BLAS and face normals; per-instance transforms. Permission failures retain box proxies. Meshes transfer outside camera polling, with paced chunks. Reinstall Lua and replace all application files. No texture or skinning export yet.
